# Changelog

## v3: November 2026
- Every placement is recorded with the error split into **depth**, **side** and **height**, plus time and target distance.
- Name entry, with the phone's own keyboard in the web version.
- 3D experience question before starting, and "Which round felt easier?" at the end.
- A coin flip decides which condition comes first (counterbalancing).
- Full results table on screen, and a CSV spreadsheet export when run on a laptop.

## v2: November 2026
- A furnished room (walls, window, rug, plant), so the task feels like a real space.
- A buddy character that celebrates good placements.
- On-screen touch buttons, so the game can be played in a phone browser.
- Two fixed rounds of 5 targets.
- Real-time shadows turned off, because they are a depth cue and would affect both conditions.

## v1: November 2026
- First prototype: move a cube to match a target sphere, with optional guides (pole and floor shadow) toggled with G.
